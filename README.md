CAD, 3D Printing & Product Development

## Current playground: Smart Motorhome

I’m currently working on integrating a **Rimor motorhome based on a Fiat Ducato** into Home Assistant.

This includes projects around:

- LIN bus communication with the motorhome electronics
- OBD-II / CAN bus vehicle data
- BLE devices and sensors
- ESP32-based gateways
- Solar and battery monitoring
- Local networking and remote access
- Touch-friendly Home Assistant dashboards

The goal is not just to display data, but to understand and integrate systems that were never designed to work with Home Assistant.
